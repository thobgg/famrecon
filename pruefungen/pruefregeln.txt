# Plausibilitätsregeln für Ortsfamilienbücher
# =============================================
# Diese Datei ist der Katalog. Der Motor (plausibilitaet.py) liest sie und
# prüft damit eine SQLite-Datenbank im OFB-Schema oder eine GEDCOM-Datei.
#
#   id | art | schwere | grenzwert | frage | herkunft
#
# art:       unmoeglich = beschreibt, was nicht sein kann (Widerspruch in den
#                         Daten; erledigt durch Korrektur)
#            muss       = beschreibt, was gelten muss (Atlas: bestaetigte Form;
#                         Treffer = nicht bestaetigt, erledigt durch Entscheidung)
# schwere:   fehler  = sperrt den Export (make check bricht ab)
#            warnung = landet in der Prüfliste, sperrt nicht
# grenzwert: leer oder Zahl mit Einheit: J Jahre, M Monate, ohne = Stück
# Zeile mit # am Anfang = Regel ausgeschaltet.
# Spalte 7 "aufloesung": WIE ein Treffer behandelt wird -- deterministisch, nie LLM:
#   regel:N     eine Feldregel des Neubaus loest ihn auf, wenn ihr Beleg im Text steht
#   mechanik:x  Bau-Mechanik (Kanten-Waechter, Verschmelzung mit hartem Beleg)
#   parser      Parserluecke: Muster suchen, Regel + Testfall bauen
#   atlas       Form-Frage: Atlas-Pflege (Status, Leitform)
#   frage       wird sichtbare Frage (/fragen, Crowd/Kirchenbuch)
#   original    nur am Kirchenbuch entscheidbar; bleibt ehrlich in der Liste
#   anzeige     kein Datenfehler, Darstellungs-/Ordnungsfrage
# Nummernkreise: 0xx Chronologie, 1xx Altersgrenzen, 2xx Struktur,
#                3xx Felder, 4xx Quellen / projektspezifisch
#
# Grenzwerte zum Vergleich: ein verbreitetes Desktop-Programm (Voreinstellungen):
#   Geschwister-Altersdifferenz 40 J, Mutter 55, Vater 85, Elter min 10,
#   Heirat min 15 / max 120, Ehepartner-Differenz 90, Lebensalter 120.
# Gramps "Daten überprüfen" (Werksdefaults): Lebensalter 90, Ehepartner 30,
#   Geschwisterabstand 8 J, Kinderspanne 25, Heirat 17-50, Mutter 17-48,
#   Vater 18-65, max 3 Ehen, 12 Kinder (Mutter) / 15 (Vater).
# Stand 29.08.2026.
